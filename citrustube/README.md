# CitrusTube 🍋

Protótipo responsivo de uma plataforma para vídeos longos, com tema de limão siciliano, painel de apoio Gaterson e laboratório de segurança de chat.

## Executar
Abra index.html em um navegador moderno ou publique somente esta pasta em um host estático para ver a interface. Não requer dependências de build.

## O que funciona
- Layout responsivo para celular, tablet e desktop.
- Pesquisa local dos cartões demonstrativos.
- Janela de apoio com níveis ilustrativos de R$ 2, R$ 5, R$ 10 e R$ 20.
- Chat local de demonstração com quatro verificações heurísticas.
- Mensagens inseridas como texto, não HTML.

## O que ainda não funciona
- Cadastro/login, banco de dados, chat público ou uploads reais.
- Player e hospedagem de vídeos.
- QR Code Pix, pagamentos e confirmação automática.
- IA real de moderação ou agentes autônomos.
- Publicação do site.

Leia SECURITY.md antes de expor o protótipo na internet. As verificações do navegador são demonstrativas e podem ser contornadas; não use este protótipo para dados privados nem para um chat público real.
